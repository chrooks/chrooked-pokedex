Every move the suggest UI can actually offer at each rung. Generated by scripts/rung_candidates.py, which reads the real pool (web/dex.py::build_move_pool, base 1.11.2 ⊕ ruleset) through the real slot rules (web/learnset_skeleton.py). The suggestor applies no learner threshold — it drops only status moves, power≤1 sentinels, signature moves, the curated rung_exclusions, and Z / Dynamax / G-Max moves. ★ = ruleset/moves/. Grey = offered here but NOT a curated ladder rung in scripts/move_coverage.py (multi-hit, charge, priority…). n = species with the move at level-up (informational only).
